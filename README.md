一个跑在 Cloudflare Workers 上的个人导航站。前端是 React + TypeScript，后端就是一个 Worker，数据存在 D1 里。自己部署一份自用，不需要服务器。

## ✨ 功能

- 分组管理站点，分组和站点都能拖拽排序
- 站点可以设为公开或私有，公开的部分访客不用登录就能看
- 登录后才能增删改，密码存的是 bcrypt 哈希，登录态用 JWT
- 深色 / 浅色主题切换
- 数据导入导出（JSON），导入时按网址自动去重合并
- 可以自定义标题、Logo、背景图和 CSS
- `script/chromeToJSON.py` 能把 Chrome 导出的书签转成可导入的 JSON

## 📖 部署手册

从零装起来，跑在 Cloudflare 上，不用服务器，免费。它比别的工具还简单：没有机器人，没有回调，表也会自己建。你真正要动手的就两件事：准备好两个值，点一次按钮。大概十分钟：

![部署流程](docs/flow.svg)

### 🧰 动手之前，先把这几样备齐

| 要备的东西 | 去哪拿 | 备注 |
|---|---|---|
| Cloudflare 账号 | cloudflare.com 注册 | 免费的就够 |
| GitHub 账号 | github.com | 点部署按钮要用 |
| 一个你想好的登录密码 | 自己定 | 下一步要把它加工成一串哈希再填，密码本身别用生日这种好猜的 |
| 一台电脑，能打开终端 | — | 只在第一步生成哈希时用一下，Mac 用自带终端，Windows 用 PowerShell |

### 🚀 开始安装

**第 1 步：先生成两个值**

导航站的登录要两样东西先备好：

① **密码哈希。** 它存的不是密码本身，是密码加工过的一串字符（行话叫哈希）。在电脑上把仓库下载下来，进到目录里，依次敲：

```bash
pnpm install
pnpm hash-password 你的密码
```

屏幕上会出来一串 `$2a$` 开头的字符，整串复制下来，就是等下要填的 AUTH_PASSWORD，一个都别落。

② **一串随机字符。** 这是给登录令牌签名的钥匙，行话叫 AUTH_SECRET。终端里敲 `openssl rand -hex 32`（Windows 没有这条命令的话，随手敲一串 32 位以上的字母数字也行，但别用单词和生日）。出来的那串复制下来备用。

> [!WARNING]
> **这两个值先存好再往下走。** 尤其是随机字符那串，丢了就得重新部署一次才能换。存进你自己的密码管理器，别只留在终端窗口里。

**第 2 步：点按钮部署**

点本页顶部的 Deploy to Cloudflare 按钮，跟着流程走。流程里会让你确认配置，其中 `wrangler.jsonc` 里有两处写着 CHANGE_ME 的，就是留给你填的：

| 名字 | 填什么 |
|---|---|
| `AUTH_PASSWORD` | 第 1 步生成的那串哈希（$2a$ 开头的整串） |
| `AUTH_SECRET` | 第 1 步备好的随机字符串 |

其余的值原样别动：AUTH_USERNAME 是登录用户名，默认 admin，想改趁现在一起改掉。

习惯用命令行的也可以全程敲命令：

```bash
pnpm install
wrangler d1 create navigation-db   # 把返回的 database_id 填回 wrangler.jsonc
pnpm hash-password 你的密码          # 生成的哈希填到 AUTH_PASSWORD
pnpm deploy
```

效果一样，按钮路线只是少敲几行字。

**第 3 步：打开站点，登录**

部署完会给你一个网址，打开它。第一次打开，数据库的三张表会自动建好，什么都不用点。用 admin（或你改的用户名）加你定的密码登录，能进去就说明全线通了。

**第 4 步：把你的网址加进去**

登录状态下新建分组、往里加站点，拖着就能排序。每个分组和每个站点都能单独设公开还是私有：设成私有的，访客打开你的导航页时根本看不到它们。以前攒的书签也不用一条条手敲，仓库里带了个小脚本，能把 Chrome 导出的书签文件转成能直接导入的格式，在页面里导入就行，重复的网址会自动合并。

✅ **验收：** ① 登录能进、能加站点；② 退出登录（或者开个无痕窗口）再打开，私有的分组和站点看不见、公开的能看见；③ 刷新页面，刚加的还在。三样齐了就完事。

### ❓ 常见问题

**登录时提示「服务器还没有设置 AUTH_SECRET」**

就是第 2 步那串随机字符没填，还是 CHANGE_ME 原样。这是个故意的拦截：不填这串，等于登录钥匙用的是公开的默认值，谁都能自己签一张管理员令牌，所以程序干脆不让登录。去 Cloudflare 后台打开这个 Worker，在 Settings → Variables 里把 AUTH_SECRET 改成你备好的随机串，保存后等一分钟再登。

**密码明明没记错，一直说用户名或密码错误**

八成是哈希的事，挨个对：生成哈希时用的密码和你现在输的是不是同一个；填的时候有没有把 $2a$ 那整串填全、头尾带没带空格或引号；AUTH_USERNAME 是不是被改过。重填一遍 AUTH_PASSWORD 最省事：重新跑一次第 1 步的命令生成新哈希，填回去。

**访客打开我的导航页，什么都看不到**

看一眼配置里的 AUTH_REQUIRED_FOR_READ：它是 true 的话，连看都要登录。想让访客能看公开部分，把它改成 false。反过来，要是连私有的也被访客看见了，先确认那些分组和站点自己的公开开关是不是开着——私有要在编辑里逐个关。

**想改登录密码**

没有「找回密码」这种东西，改法就是重走一遍生成：用新密码跑一次 hash-password，把新哈希填进 AUTH_PASSWORD，保存。旧密码立刻失效。

**页面打开是空白或者样式乱了**

刚部署完等一分钟再强刷一次，多半是缓存。再不行，去 Cloudflare 后台看这个 Worker 的部署记录是不是最新一次成功了。

**数据会不会丢？**

分组、站点、设置都存在 Cloudflare 的数据库里，重新部署代码不会动它。但它就这一份，没有第二份保险——隔段时间在页面里导出一次数据存自己手里，真出事导回去就行。

### 🔒 安全：可能出事的地方

导航页看着人畜无害，但它挂在公网上、带着一个登录门，该堵的洞一个不少。

**程序已经堵上的**

- **用默认钥匙冒充管理员。** 登录令牌靠 AUTH_SECRET 签名。这串没改（还是 CHANGE_ME 或者干脆没填）的时候，程序直接拒绝登录，用公开默认值签出来的令牌也一律不认。这一条是硬拦截，不是提醒。
- **密码不存明文。** 数据库和配置里只有密码的哈希，拖了库也还原不出你的密码，前提是你密码本身别太好猜。
- **慢慢猜密码。** 同一个地址 15 分钟内最多试 5 次登录，靠人手和脚本慢慢撞都撞不动。
- **访客翻私有内容。** 公开和私有的过滤是在接口层做的，访客的请求根本拿不到私有分组和站点的数据，不是页面上藏起来那么简单。

**要靠你自己注意的**

- **这个仓库是公开的，千万别把真值提交进去。** 你在自己电脑上把 AUTH_PASSWORD 和 AUTH_SECRET 填进 wrangler.jsonc 没问题；但要是哪天把这份改过的代码推回公开仓库，全世界都能拿你的哈希和签名钥匙去开你的站。公开分享代码之前，先把这两处换回 CHANGE_ME。
- **AUTH_SECRET 泄露 = 别人能自己签管理员令牌。** 不用知道你的密码也进得来。怀疑泄露，立刻换一串新的填回去保存——换完那一刻，所有旧令牌同时作废，干净利落。
- **别图省事关掉登录。** 把 AUTH_ENABLED 改成 false，页面是随便进了，但谁都能改你的导航、往里面塞钓鱼链接。只在自己电脑上本地玩玩可以，挂在公网上的千万别关。
- **自定义 CSS 只给自己用。** 设置里能写自定义样式，那是给登录用户改自己页面的。账号别借人，道理和别把家门钥匙借人一样。
- **GitHub 和 Cloudflare 账号开两步验证。** 这两个账号任意一个被盗，站点和代码一起丢。

### 📌 最后，两条保命的提醒

1. **AUTH_SECRET 和密码哈希，存进自己的密码管理器。** 前者丢了要重新部署才能换，后者忘了只能重设——都不是大事，但存好能省一趟折腾。
2. **定期导出一份数据。** 页面里就有导出，点一下存下来。数据只在 Cloudflare 那一份，出任何事，这份导出就是你的后悔药。

装完之后日常不用操心，它在 Cloudflare 上自己跑着。真遇到这份手册里没写的情况，把报错的原文记下来——不管找谁帮忙，原文比描述有用十倍。

## 💻 本地运行

需要 Node.js 和 pnpm。

```bash
pnpm install
pnpm dev
```

本地开发时没有后端数据，页面会用 `src/API/mock.ts` 里的示例数据。打包：`pnpm build`。

## 📁 目录

- `src/` 前端代码，`src/API/` 是和 Worker 对接的接口层
- `worker/index.ts` Worker 入口，处理 API 和登录校验
- `init_table.sql`、`migrations/` 数据库结构（新部署会自动建表，这两份留作参考）
- `scripts/hash-password.ts` 生成密码哈希的小工具
- `script/chromeToJSON.py` Chrome 书签转换脚本
